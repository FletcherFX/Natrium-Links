## ⚖️ О проекте
Этот репозиторий представляет собой легковесный, оптимизированный «линктри-сайт» (навигатор), написанный на чистом HTML/CSS/JS. Он предназначен для удобной агрегации ссылок проекта NATRIUM в одном месте.
